# 范围与证据

## 范围

- 每个任务都从用户明确填写的目标开始，默认只允许当前输入的 URL 源站。
- 页面或工具发现的关联域名、IP、子域和第三方服务不会自动加入范围。
- 账号密码仅用于用户选择的测试目标；不得写入任务日志、知识库或模型提示。
- 任务计划与工具执行分开。模型可以建议下一步，程序负责确认范围和工具能力。
- 先做只读基线；需要主动验证时按《非破坏性测试与确认即停边界》执行，高风险动作只做到证明漏洞存在。

## 证据

- 区分已确认、待复核和未验证内容。
- 结论应能关联到具体目标、时间、观察结果和复现条件。
- 报告只写实际收集到的事实；不要把推测包装成已验证发现。
- 页面观察优先记录结构摘要，不保存表单值、Cookie、Token 或密码。
- 高风险验证记录动作、时间、一次性请求、响应差异和停止原因；确认后不再重放。
