# 可编辑验证模板库

这里集中维护 hah-agent 使用的低影响验证模板。它们是待填写的占位模板，不是可直接运行的攻击 payload。改动后保存到本机 RAG，即可在任务检索中引用；修改前请保留边界、来源和停止条件。原始报告、目标 URL、真实账号、Cookie/Token、个人数据以及可利用攻击语句不得粘贴到这里。


## 场景化选型入口

本文件保留低影响占位模板；具体场景选型、clown 与真实报告的 payload 对比、每个模板的完整度和停止条件，见：

- `skills/payload-selection.md`：场景矩阵、选型流程、优先级规则。
- `payload-catalog.json`：机器可读目录，供 `/api/payloads/select` 使用。
- `report-payload-notes.md`：从本轮报告样本中提取的 payload 缺口和对比结论。
- `skills/clown/`：导入的 clown-src-6k-skill 知识库原文。

选型时先按“资产面 → 输入面 → 回包特征 → 技术栈”定位，再取一个主模板和一个对照。`payload-catalog.json` 中高风险非破坏条目可自动执行到确认漏洞存在；`destructive: true` 的条目仅人工复核。

## 通用模板字段

每个模板按以下卡片维护：

- **适用资产/类别**：Web、云、Android、iOS、鸿蒙 NEXT、小程序及风险类别。
- **来源**：报告/训练资料的文件名或主题类别，以及 `clown-src-6k-skill` 的分类参考（如有）。
- **适用条件**：只描述已授权、可确认的测试功能和环境。
- **模板**：仅使用 `<占位符>` 和无害标记；不得放攻击语法、真实目标或秘密。
- **对照/证据**：记录基线、测试结果、必要脱敏证据。
- **停止条件**：写明副作用、越权、真实数据、环境版本不符等触发项。

## Web

### 输入校验的无害差异观察

- 来源：某安全团队整理的 Web 漏洞集合资料的数据校验类别；参考 clown skill 按功能特征选模块的组织方式。
- 适用条件：已确认是只读搜索/展示字段，且请求本身不会创建或修改数据。
- 模板：`字段=<目标字段名>；值=<本次唯一无害标记，例如 hah-check-<随机短编号>>`
- 对照/证据：先记录普通值的状态码、响应字段类型和长度，再记录标记值的同类信息；仅保留脱敏差异。
- 停止条件：需要控制语法、表达式、脚本、SQL 片段，或端点的副作用不清楚时停止，标记“待复核”。

### 两个自有主体的访问控制对照

- 来源：Web 报告中的认证/访问控制类别；clown `idor-test` 仅作类别索引，不复制其中利用操作。
- 适用条件：有两个授权测试账号，且对象由测试者创建、数据为合成数据。
- 模板：`主体 A → 合成对象 A；主体 B → 同一合成对象 A；预期：B 收到授权拒绝。`
- 对照/证据：记录主体别名、合成对象别名、允许/拒绝状态与时间，不保存对象内容。
- 停止条件：对象属于第三方/真实用户、需要枚举 ID 或响应包含真实个人数据时立即停止。

### 安全配置与信息暴露观察

- 来源：Web 报告中的通信、会话、响应头和敏感信息类别。
- 适用条件：授权源的正常页面或配置审阅。
- 模板：`观察项=<TLS/安全响应头/Cookie 属性/公开页面字段>；记录=<是否存在及配置值，不抄秘密>`
- 对照/证据：记下授权源、时间、状态和配置项；密钥、令牌、个人信息只记录“发现该类别”并脱敏。
- 停止条件：需要下载批量数据、访问未授权子域或读取真实秘密时停止。

### 认证与会话配置观察

- 来源：历史 Web 报告中重复出现的认证/验证码/会话类别；Web 漏洞集合；clown 的认证模块仅作分类索引。
- 适用条件：授权测试源、一个专用测试账号，且不会触发账户锁定、短信/邮件发送或其他副作用。
- 模板：`账号=<测试账号别名>；观察项=<TLS/会话 Cookie 属性/登录错误提示一致性/退出后策略文档审阅>`。登录仅由用户人工提交一次。
- 对照/证据：记录配置项是否存在、错误提示是否暴露账号状态、观察时间；Cookie/Token 内容只记“已脱敏”。
- 停止条件：验证码绕过、口令猜测、重放、并发或多次尝试、密码修改、登出/注销/令牌撤销、真实账号信息暴露。

### 访问控制的合成对象差分

- 来源：历史报告中重复出现的未授权访问/越权类别；clown `idor-test` 只用于识别风险类别。
- 适用条件：测试者自有的 A/B 两个测试主体、预先创建的合成对象、只读详情页。
- 模板：`主体=<B 测试别名>；对象=<A 合成对象别名>；预期=<拒绝访问>`。对象标识通过测试环境手工登记，不递增、不枚举。
- 对照/证据：与 B 访问其自身合成对象的状态码/字段结构对照；只记录授权结果和脱敏字段名。
- 停止条件：对象并非测试者创建、回包包含真实个人/业务数据、需要批量遍历或接口语义可能变更数据。

### 文件功能的静态边界审阅

- 来源：历史 Web 报告中的文件处理类及 Web 漏洞集合；clown 文件上传/路径类仅作分类索引。
- 适用条件：优先审阅代码、配置、接口说明；如需动态观察，仅使用不会提交的本地表单校验和已登记的测试环境说明。
- 模板：`功能=<上传/下载/预览>；审阅项=<扩展名白名单/大小限制/存储隔离/授权校验>`。
- 对照/证据：保存配置项或页面校验提示的脱敏截图/文本；默认不向服务端上传文件、不请求系统路径。
- 停止条件：验证需要上传、覆盖、解析、读取服务器文件、路径穿越或下载真实对象时停止。

### 云策略最小权限审阅

- 来源：历史云/配置暴露类报告与云资产检查类别。
- 适用条件：已有策略文本、只读控制台视图或厂商提供的策略模拟器。
- 模板：`主体=<测试角色别名>；资源=<合成资源标识>；动作=<仅读取策略中的动作名，不发送请求>`。
- 对照/证据：记录策略模拟器的允许/拒绝结论或策略中权限范围；不填真实账号、密钥、桶名或对象名。
- 停止条件：需要真实列举、下载、覆盖、删除对象，读取云元数据或取得临时凭证时停止。

## Android

### APK 静态配置检查

- 来源：Android 入门培训、Android 测试用例、某厂商 Android 指南/报告模板。
- 适用条件：用户提供且已登记授权的 APK 文件。
- 模板：`包名=<包名>；版本=<版本>；检查项=<签名摘要/debuggable/allowBackup/导出组件/权限>`
- 对照/证据：记录 APK 哈希、版本、签名证书摘要、静态配置和值；只报告配置，不据此断言可利用。
- 停止条件：需要重打包、篡改安装包、执行导出组件、恢复备份或改变设备设置时停止。

### 模拟器中的日志与存储基线

- 来源：Android 培训及 Android 测试用例的日志、本地存储类别。
- 适用条件：隔离模拟器、测试构建、专用测试账号及合成数据。
- 模板：`包名=<授权包名>；测试数据=<合成标记>；观察范围=<应用可见日志/测试目录>`
- 对照/证据：记录日志类别、脱敏字段名、测试构建版本；不保存凭据、令牌或数据库正文。
- 停止条件：发现真实用户数据，或必须 root、导出数据库、读取其他应用目录时停止。

## iOS

### 构建配置审阅

- 来源：iOS 指南、培训资料与安全评估报告模板。
- 适用条件：用户提供且授权的 IPA/Simulator 构建。
- 模板：`Bundle ID=<标识>；版本=<版本>；检查项=<签名/Entitlement/ATS/权限说明>`
- 对照/证据：记录构建哈希、签名摘要和配置项；对旧材料涉及的系统行为按当前 iOS/Xcode 版本重新核验。
- 停止条件：需重签、篡改资源、注入代码、越狱或绕过保护时停止。

### 合成数据的本地保护观察

- 来源：iOS 培训与漏洞案例中的本地存储、数据库、日志、后台截图类别。
- 适用条件：Simulator 可运行的测试构建、测试账号和合成数据。
- 模板：`合成数据标记=<hah-check-编号>；观察项=<应用可见日志/测试界面切后台后的展示>`
- 对照/证据：只记录是否暴露及脱敏位置，不导出 Keychain、数据库或真实设备文件。
- 停止条件：出现真实隐私，或需要越狱、SSH、转储工具时停止。

## 鸿蒙 NEXT

### HAP/HSP 与 Ability 静态审阅

- 来源：鸿蒙 NEXT 应用渗透测试指南（2026 第二版）；须核对文档与设备/SDK 版本。
- 适用条件：授权 HAP/HSP 包和登记的测试设备。
- 模板：`bundleName=<包名>；版本=<版本>；检查项=<签名摘要/权限/Ability 导出配置>`
- 对照/证据：记录包哈希、系统/SDK 版本、静态配置和签名摘要。
- 停止条件：需请求密钥协商、提取应用市场凭据、下载非授权包或测试跨设备访问时停止。

## WAF 绕过变形模板

WAF 绕过只作为已授权测试中的**静态候选模板**，不自动发送、不联网、不爆破。完整前提、变形顺序、拦截判定和停止条件见 `skills/waf-bypass.md`；机器可读候选见 `payload-catalog.json` 的 `bypassVariants` 字段和 `lib/waf-bypass.js` 的 `generateBypassVariants()`。

### LFI 路径表达

- 适用条件：已授权的只读文件读取模板，已记录明文路径的基线和状态码/长度/耗时。
- 模板：`....//....//<FILE>`、`..//..//<FILE>`、`..%2f..%2f<FILE>`、`%252e%252e%252f<FILE>`；一次只取一个维度。
- 还原说明：按 `decodeSteps` 逐层解释 URL 解码和路径归一化；`%00` 只作为历史兼容示例，现代 PHP 5.3.4+ 已不接受空字节截断。
- 停止条件：连续 403/406、出现告警、读到授权范围外文件或任何写入副作用时停止。

### SQLi 注释与空白

- 适用条件：已授权的只读库名/版本或布尔差分验证。
- 模板：`<PARAM>=<VALUE>'/**/AND/**/1=1-- -`、`<PARAM>=<VALUE>'/*!50000AND*/1=1-- -`、`<PARAM>=<VALUE>'%09AND%091=1-- -`。
- 还原说明：`/**/` 和版本化注释由数据库按自身规则处理；`%09`、`%0a`、`+` 由接收端解码为空白。关键字必须保持可读。
- 停止条件：不写库、不删表、不读取业务表；慢查询、连接池告警或连续拦截时停止。

### XSS 实体与十六进制实体

- 适用条件：已授权的反射/属性上下文，只做弹窗或 DOM 标记。
- 模板：`&lt;script&gt;alert(1)&lt;/script&gt;`、`&#x3c;script&#x3e;alert(1)&#x3c;/script&#x3e;`。
- 还原说明：实体形式本身不含原始尖括号标签；只有接收端发生二次解码且进入可执行上下文时才需要继续判断。
- 停止条件：不窃取 Cookie、不调用外部回调；出现跨源请求或真实数据时停止。

### 命令注入只读探针

- 适用条件：已授权的诊断/只读命令上下文。
- 模板：`;id`、`|id`、`%0aid`、`;cat$IFS<FILE>`、`;{cat,<FILE>}`。
- 还原说明：分隔符由 shell 解释，`$IFS` 展开为空白，`{cat,<FILE>}` 展开为只读文件命令。
- 停止条件：不写文件、不删数据、不下载执行、不反弹 shell、不持久化；出现命令执行副作用立即停止。

### 上传扩展名

- 适用条件：已授权的无害标记文件上传，文件内容只含静态文本。
- 模板：`<TEST>.HTML`、`<TEST>.html.txt`、`<TEST>%2ehtml`、`<TEST>.html.`。
- 还原说明：观察服务端取哪一段扩展名、是否解码点号、是否忽略尾随点；不根据单次响应断言可执行。
- 停止条件：不上传脚本、不覆盖他人文件；验证后按授权流程清理测试文件。

## 修改说明

修改模板时只补充已审核的占位符、适用条件、基线、证据和停止条件。任何需要真实攻击语法才能表达的验证，应另标“未纳入自动化模板”，由技术指导给出审阅结论，不写入此库。
