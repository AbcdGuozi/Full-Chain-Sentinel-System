# 报告与训练资料归纳模式

本技能只吸收用户提供资料中的通用风险分类、检查条件和证据字段，不保存原始报告、历史目标、真实 URL/接口、凭据、个人信息、利用链或可直接执行的攻击 payload。每条归纳必须能追溯到本地资料的主题类别；实际使用时说明“资料线索”，不得把历史报告结论当作当前目标事实。

## 来源与归纳范围

- **Web**：某安全团队整理的 Web 漏洞集合资料，归纳认证/会话、输入校验、通信、文件处理与信息暴露类别。
- **Android**：内部培训资料、Android 测试用例、某厂商 Android 测试指南及安全评估报告模板，归纳签名/完整性、备份/调试、导出组件、存储/硬编码、日志、WebView/TLS。
- **iOS**：内部培训、iOS 客户端渗透测试指南、iOS 渗透测试方法与漏洞案例、iOS 安全评估报告模板，归纳签名/ATS/TLS、权限、存储/Keychain/数据库、日志/后台截图、认证与验证码。
- **鸿蒙 NEXT**：鸿蒙 NEXT 应用渗透测试指南（2026 第二版），归纳 HAP/HSP 签名、权限、Ability、资源/日志以及版本时效注意事项。
- **方法结构参考**：`clown-src-6k-skill` 的资产特征分类、相关模块选择、任务分解和报告组织方式；不复制其攻击 payload 与利用操作。

## Web 与接口的任务线索

Web 漏洞集合重点涉及认证与会话、输入验证、敏感信息、文件处理、通信安全、访问控制、配置与响应头。clown-src-6k-skill 的模块划分可用作“风险类别索引”和工作卡片组织方式（按目标特征挑相关类别，先确认输入点与证据，不全量套用）。其中的自动测绘、WAF 绕过、可执行利用链、认证绕过、文件读取/上传、SSRF 到内网、真实对象越权写操作等内容不进入本 agent 执行建议。

| 类别 | 检查条件 | 无害验证模板 | 证据与停止条件 |
|---|---|---|---|
| 认证/会话 | 已有授权登录入口或配置材料 | 专用账号单次人工登录；审阅 Cookie 属性、TLS 与错误信息 | 记录属性与脱敏状态；遇到重复尝试、验证码绕过、改密、登出或撤销立即停止 |
| 输入/注入 | 有明确只读搜索或展示字段 | `字段=<唯一无害标记>`，比较正常值与标记值 | 记录状态/结构/错误类别；不得拼接 SQL、表达式、脚本或控制语法 |
| 访问控制 | 有两个自有测试主体与合成对象 | A 访问 A 的合成对象；B 对同一合成对象预期拒绝 | 记录主体标签、合成 ID 与授权结果；真实对象或遍历需求立即停止 |
| 文件/路径 | 有授权测试目录和无害文本样本 | 审阅配置或对已确认只读的测试文件做边界检查 | 不读系统文件、不覆盖/上传/删除文件、不使用路径穿越 payload |
| 浏览器/前端 | 已确认授权源 | 查看页面结构、资源引用、安全响应头与手工登记只读路径 | 脱敏 URL/响应；跨源、未知方法、危险命名或副作用可能性立即停止 |
| 信息泄露 | 页面、前端资源或日志中出现疑似敏感字段 | 只标记字段类别、位置及脱敏样本 | 不保存密钥/token/个人数据，不批量获取或下载 |
| 云策略 | 获得策略文档或只读云控制台授权 | 静态审阅或策略模拟器+合成资源标识 | 记录允许/拒绝结论；任何真实对象读写、列举或元数据请求停止 |

## 移动端线索

Android 资料反复覆盖签名/完整性、debuggable/备份、导出组件与权限、本地存储/硬编码、日志、WebView/TLS。iOS 资料覆盖签名/Entitlement、ATS/TLS、沙箱与本地数据库/Keychain、日志、后台截图、认证/验证码。鸿蒙 NEXT 资料覆盖 HAP/HSP 签名、权限、Ability 导出、资源和日志，并强调系统版本时效。按 `mobile-app-testing.md` 执行静态审阅与合成数据基线；资料中的 root/jailbreak、Frida、重签篡改、凭据/数据库转储不转成 agent payload。

## clown-src-6k-skill 的安全复用方式

- 可复用：按资产特征选择相关检查类别、先确认授权源、任务分解、记录证据、报告复核的组织形式。
- 不复用为执行步骤：种子域扩展/自动扫描、WAF 绕过、SQL/模板/命令/XXE/SSRF/LFI/XSS 等利用 payload、身份绕过、对真实对象写越权、读取真实数据、上传或状态变更。
- 若模型从知识库召回了不符合边界的内容，技术指导应将其降级为审阅问题或拒绝执行，并指出资料与当前边界冲突。

## 报告最小字段

标题、授权资产标识、来源类别、前置条件、测试环境/版本、观察时间、验证方法（注明只读/合成数据）、基线与结果、脱敏证据引用、影响判断、修复建议、复测结论。结论分为“已确认”“待复核”“未验证”；不能由历史资料或模型推断代替当前证据。
