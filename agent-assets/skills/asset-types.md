# 资产类型工作流

## Web

用浏览器收集首页结构和同源入口，随后由操作者选择需要验证的业务功能。

## 云

先登记云账号/项目边界和只读凭证范围。第一版仅保留计划与证据记录，不调用云平台 API。

## App

先确认 App 包名、测试设备和测试账号。模拟器连接器只枚举已启动的本地 Android/iOS 设备，并可启动用户指定的已安装 App。

## 小程序

记录小程序名称、测试环境和入口页面。第一版仅规划工作流；运行态抓包和小程序平台 API 尚未接入。
