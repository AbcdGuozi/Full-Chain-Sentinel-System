| 等级 | 说明 |
|---|---|

| 高危 | 可获取敏感权限、越权访问关键数据或稳定利用 |
| 中危 | 需要特定条件，影响范围有限 |
| 低危 | 信息暴露或加固缺失，单独利用价值低 |
